# module:new

Создает новый модуль (обычный или дочерний) и размещает его в папке `modules`

## Параметры

- `name` — обязательный аргумент, символьный код модуля, например `vendor.module`;
- `title` — обязательный аргумент, название модуля (языковая фраза `*_MODULE_NAME`);
- `--parent` (кратко `-p`) — необязательная опция, символьный код родительского модуля для дочернего модуля;
- `--partner` — необязательная опция, название партнёра (языковая фраза `*_PARTNER_NAME`);
- опциональные параметры для добавления необязательных конкретных файлов, описаны в `Commands/NewModule/Files.php`.

Каждая запись в `Files.php` для необязательного файла выглядит так:
```php
    '<короткий символьный код параметра>' => [
        'path' => ... // файл или каталог в шаблоне относительно шаблона
        'description' => ... // описание параметра для `--help`.
    ]
```
где `<короткий символьный код параметра>` указывается как параметр `--file-<короткий символьный код параметра>`

Например, для файла файл `options.php` указан ключ `options` как
```php
    'options' => [
        'path' => 'options.php',
        'description' => 'Добавить файл options.php из шаблона',
    ]
```
Теперь без указания параметра `--file-options` файл `options.php` не будет скопирован. Файлы и каталоги, которых нет в `Files.php`, копируются всегда.

## Пример

```
vendor/bin/bitrix-module-helpers module:new alanmilne.honeytypes "Любимые виды мёда Винни Пуха" --parent=alanmilne.pooh
```
